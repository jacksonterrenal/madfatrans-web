# MADFATRANS S.A. · Página web

Sitio de una sola página para MADFATRANS S.A., empresa de transporte terrestre pesado en Guayaquil, Ecuador.

- `index.html`: la página completa (HTML, CSS y JavaScript en un solo archivo).
- `img/`: logo, ícono y fotos de la flota.

El formulario de cotización no necesita servidor: arma el mensaje y lo abre en WhatsApp (+593 99 222 5585).

## Publicar
Sitio estático: se puede publicar gratis en Netlify, Cloudflare Pages o GitHub Pages apuntando a la raíz del repositorio.
